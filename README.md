# 리듬타운

국악 기반 리듬 게임입니다. 첫 곡 **「달빛 장터」**(국악 힙합·조선팝, 92 BPM, 약 1분 27초)는
가야금·대금·장구·꽹과리·징 소리와 힙합 드럼·베이스를 브라우저에서 직접 합성해 연주합니다(음원 파일 없음).

## 실행

`index.html`을 브라우저로 열면 실행됩니다. 별도 설치나 빌드가 필요하지 않습니다.
Google Fonts에 연결되지 않아도 시스템 글꼴로 동작합니다.

## 플레이 방법

1. 시작 화면에서 1인/2인, 난이도(하·중·상)를 고르고 **리듬 시작하기**를 누릅니다.
2. 박 소리 네 번(하나·둘·셋·넷) 뒤 곡이 시작됩니다.
3. 떨어지는 노트가 아래 단청 무늬 판정선에 닿을 때 해당 키를 누릅니다.

| 모드 | 키 |
| --- | --- |
| 1인 | `D` `F` `J` `K` (또는 방향키 ← ↓ ↑ →, 화면 터치) |
| 2인 | 1P `A` `S` `D` `F` / 2P `J` `K` `L` `;` (또는 방향키) |

- `Esc`(또는 `P`, 오른쪽 위 Ⅱ 버튼): 일시정지. 다른 탭으로 가도 자동으로 멈춥니다.
- 일시정지 화면에서 판정 보정(블루투스 이어폰처럼 소리가 늦을 때)과 타격음을 바꿀 수 있습니다.
- 결과 화면에서 `R`: 다시 하기.

### 판정 (판소리 추임새)

| 판정 | 점수 비율 | 하 | 중 | 상 |
| --- | --- | --- | --- | --- |
| 얼쑤! | 100% | ±50ms | ±42ms | ±34ms |
| 좋다! | 70% | ±95ms | ±80ms | ±66ms |
| 잘한다 | 40% | ±140ms | ±120ms | ±100ms |
| 어이쿠 | 0% (연속 끊김) | | | |

점수는 100만 점 만점, 정확도에 따라 S 명창 · A 고수 · B 한량 · C 풋내기 등급을 받습니다.
놓친 노트가 없으면 "완창! 풀콤보". 2인 플레이는 점수가 높은 쪽이 승리합니다.

### 난이도

| | 노트 수 | 초당 노트 | 노트 속도 | 특징 |
| --- | --- | --- | --- | --- |
| 하 | 116 | 1.3 | 느림 | 박자(4분음표)마다, 동시치기 없음 |
| 중 | 191 | 2.2 | 보통 | 8분음표, 징·후렴 첫 박 동시치기 |
| 상 | 331 | 3.8 | 빠름 | 16분음표 엇박, 덩(양손) 동시치기 |

노트는 실제 연주와 같은 데이터에서 만들어집니다. 선율(가야금·대금)은 음 높이에 따라 왼쪽(낮음)→오른쪽(높음),
장구는 쿵(궁편)=왼쪽, 덕(채편)=오른쪽, 덩(양손)=양쪽 동시, 징은 가운데(하) 또는 양쪽 동시로 나옵니다.

## 파일

- `index.html`: 화면 구조 (시작 화면 + 게임 화면)
- `style.css`: 디자인, 반응형 레이아웃, 상호작용 효과
- `main.js`: 시작 화면 선택 상태, 게임 시작
- `js/song.js`: 곡 데이터(악기 연주 이벤트)와 난이도별 채보 생성
- `js/audio.js`: Web Audio 악기 합성, 곡 재생, 오디오 기준 게임 시계
- `js/game.js`: 노트 화면, 입력·판정·점수, 일시정지, 결과
- `tests/chart.test.js`: 채보 검사
- `tests/browser_smoke.py`: 브라우저 실행 검사(선택, Playwright·Chrome 필요)
- `vendor/liquid-glass-js/`: 외부 버튼 효과 라이브러리 원본(현재 게임에서는 사용하지 않음)

## 검사

```bash
for f in main.js js/*.js; do node --check "$f"; done        # 문법
node tests/chart.test.js                                  # 채보
python3 tests/browser_smoke.py [스크린샷_폴더]            # 브라우저(선택, 약 2분)
```

시연용 자동 연주: `index.html?auto=1`
