# 리듬타운

국악 기반 리듬 게임입니다. 곡 세 개 중 하나를 골라 1인 또는 2인이 함께 플레이합니다.

| 곡 | 종류 | 템포 | 길이 |
| --- | --- | --- | --- |
| 신명 조선힙합 1 | 원곡 음원(mp3) | 100 BPM | 1:37 |
| 신명 조선힙합 2 | 원곡 음원(mp3) | 110 BPM | 1:51 |
| 달빛 장터 | 브라우저 합성(가야금·대금·장구·꽹과리·징 + 힙합 드럼) | 92 BPM | 1:27 |

원곡 두 곡은 사용자가 준 한 파일(두 곡이 이어 붙은 WAV, 3:28)을 곡 사이 무음(96.8초)에서 나눈 것입니다.

## 실행

- **웹 서버로 열기(권장)**: 원곡 음원은 브라우저가 파일을 내려받아야 하므로 웹 서버가 필요합니다.
  예) 이 폴더에서 `python3 -m http.server 8000` 후 http://127.0.0.1:8000/ , 또는 주원 사이트 https://joowon.axcoding.co.kr/rhythm/
- `index.html`을 파일로 직접 열면 합성곡 「달빛 장터」만 플레이할 수 있습니다(원곡을 고르면 안내가 나옵니다).

## 플레이 방법

1. 시작 화면에서 곡, 1인/2인, 난이도(하·중·상)를 고르고 **무대 열기**를 누릅니다.
2. 박 소리 네 번(하나·둘·셋·넷) 다음 박이 곡의 첫 박입니다.
3. 떨어지는 노트가 아래 네온 판정선에 닿을 때 해당 키를 누릅니다.

| 모드 | 키 |
| --- | --- |
| 1인 | `D` `F` `J` `K` (또는 방향키 ← ↓ ↑ →, 화면 터치) |
| 2인 | 1P `A` `S` `D` `F` / 2P `J` `K` `L` `;` (또는 방향키) |

- `Esc`(또는 `P`, 오른쪽 위 Ⅱ 버튼): 일시정지. 다른 탭으로 가도 자동으로 멈춥니다.
- 키를 누르면 레인마다 다른 북소리가 납니다(청 큰북 '둥', 적 장구 '덩', 황 장구 '덕', 백 손뼉). 박자가 정확할수록 크고 묵직하게 울리고(얼쑤 > 좋다 > 잘한다), 박자를 놓치면 '삑사리' 소리와 붉은 X·'삑!' 표시가 나옵니다(점수는 바뀌지 않음).
- 맞히면 빛 원·퍼지는 고리·불꽃 조각·빛줄기가 터지고 받침 원이 눌렸다 튀어나오며, 얼쑤에는 판이 '쿵' 눌리고 삑사리에는 좌우로 흔들립니다(동작 줄이기 설정이면 흔들림·불꽃 생략).
- 일시정지 화면에서 판정 보정(블루투스 이어폰처럼 소리가 늦을 때)과 타격음(북소리·삑사리)을 바꿀 수 있습니다.
- 결과 화면에서 `R`: 다시 하기.

### 판정 (판소리 추임새)

| 판정 | 점수 비율 | 하 | 중 | 상 |
| --- | --- | --- | --- | --- |
| 얼쑤! | 100% | ±50ms | ±42ms | ±34ms |
| 좋다! | 70% | ±95ms | ±80ms | ±66ms |
| 잘한다 | 40% | ±140ms | ±120ms | ±100ms |
| 어이쿠 | 0% (연속 끊김) | | | |

점수는 100만 점 만점, 정확도에 따라 S 명창 · A 고수 · B 한량 · C 풋내기 등급을 받습니다.
놓친 노트가 없으면 "완창! 풀콤보". 2인 플레이는 점수가 높은 쪽이 승리합니다.

### 난이도

| | 노트 간격 | 초당 노트(원곡 / 달빛 장터) | 노트 속도 |
| --- | --- | --- | --- |
| 하 | 박(4분음표)마다, 동시치기 없음 | 1.35 / 1.3 | 느림 |
| 중 | 8분음표, 가끔 동시치기 | 2.4 / 2.2 | 보통 |
| 상 | 16분음표 엇박, 동시치기 | 4.2 / 3.8 | 빠름 |

- 원곡: `tools/analyze_song.py`가 음원을 분석해 박(템포·첫 박)을 찾고, 소리가 센 자리에 노트를 둡니다.
  저음(킥)일수록 왼쪽, 밝은 소리(하이햇·꽹과리)일수록 오른쪽 레인입니다.
- 달빛 장터: 노트가 합성 연주 데이터에서 나옵니다(선율은 음 높이, 장구 쿵=왼쪽·덕=오른쪽·덩=양쪽).

## 원곡 추가하기

```bash
pip install numpy lameenc            # 처음 한 번
python3 tools/analyze_song.py "음악/파일.wav" 곡id --title "곡 제목" --subtitle "원곡 · 장르" [--start 초] [--end 초] [--segments "0=BPM"]
```

- 결과: `audio/곡id.mp3`(웹용), `js/songs/곡id.js`(곡 정보·채보). `index.html`에 `<script src="js/songs/곡id.js" defer></script>`를 `js/songs.js` 앞에 추가하면 곡 선택에 나타납니다.
- 원본 WAV는 `음악/`에 두며 Git에 올리지 않습니다(`.gitignore`).
- 템포를 모르면 `--segments`를 빼면 자동으로 찾습니다. 여러 곡이 이어 붙은 파일은 `--start`/`--end`로 나눕니다.
- mp3 앞의 인코더 지연(23ms)은 `audioDelay`로 기록되어 재생 때 자동으로 맞춥니다.

## 파일

- `index.html`: 화면 구조 (시작 화면 + 게임 화면)
- `style.css`: 네온 디자인, 반응형 레이아웃, 상호작용 효과
- `main.js`: 시작 화면(곡 카드·선택 상태), 음원 불러오기, 게임 시작
- `js/song.js`: 합성곡 「달빛 장터」 데이터와 채보 생성, 난이도 설정(판정 범위·노트 속도)
- `js/songs/*.js`: 원곡 곡 정보와 채보(`tools/analyze_song.py`가 만든 파일)
- `js/songs.js`: 곡 목록(원곡·합성곡을 같은 모양으로 묶음)
- `js/audio.js`: Web Audio 악기 합성, 음원 재생, 오디오 기준 게임 시계
- `js/game.js`: 노트 화면, 입력·판정·점수, 일시정지, 결과
- `audio/*.mp3`: 원곡 웹용 음원
- `tools/analyze_song.py`: 원곡 분석·채보·mp3 변환
- `tests/chart.test.js`: 채보 검사, `tests/browser_smoke.py`: 브라우저 실행 검사(선택, Playwright·Chrome 필요)
- `vendor/liquid-glass-js/`: 외부 버튼 효과 라이브러리 원본(현재 게임에서는 사용하지 않음)

## 검사

```bash
for f in main.js js/*.js; do node --check "$f"; done        # 문법
node tests/chart.test.js                                  # 채보
python3 tests/browser_smoke.py [스크린샷_폴더]            # 브라우저(선택, 약 4분, 임시 로컬 웹 서버를 띄움)
```

시연용 자동 연주: `index.html?auto=1`
