# 리듬타운

국악 기반 리듬 게임의 시작 화면입니다.

## 실행

`index.html`을 브라우저로 열면 실행됩니다. 별도 설치나 빌드가 필요하지 않습니다.
Google Fonts에 연결되지 않아도 시스템 글꼴로 동작합니다.

## 기능

- 1인 / 2인 플레이 선택
- 상 / 중 / 하 난이도 선택 및 설명
- 버튼의 마우스 오버 색상·크기·그림자 효과
- 키보드 Tab과 방향키로 선택, Enter 또는 Space로 버튼 실행
- 선택 결과 확인 창 (Escape 또는 돌아가기 버튼으로 닫기)
- 모바일 화면 및 동작 줄이기 설정 지원

실제 곡 선택과 게임 플레이는 아직 구현하지 않았습니다.

## 파일

- `index.html`: 화면 구조
- `style.css`: 디자인, 반응형 레이아웃, 상호작용 효과
- `main.js`: 선택 상태와 시작 확인 창

JavaScript 문법 확인: `node --check main.js`
